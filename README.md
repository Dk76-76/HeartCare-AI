# 🫀 CardioAI: Heart Disease Predictor

🌐 **[Live Demo Available Here](https://heartcare-ai-jwy4.onrender.com)**

CardioAI is a simple and secure Machine Learning web application. It predicts the probability of heart disease based on basic clinical parameters (like Age, Blood Pressure, and Cholesterol).

## 📌 What It Does
* **Takes Input:** Accepts patient data and cardiac test results.
* **AI Prediction:** Uses an AI model to calculate the risk percentage of heart disease.
* **Generates Report:** Creates a clean, easy-to-read medical report.
* **100% Private:** No user data is saved or sent to any server.

## 🛠️ Built With
* **Frontend:** HTML, CSS, JavaScript
* **Backend / ML:** Python, Machine Learning (Scikit-Learn)
* **Hosting:** Render

## 🚀 How to Run 
1. Download or clone this repository.
2. Install the required dependencies (`pip install -r requirements.txt`).
3. Run the main app file (e.g., `python app.py`).
4. Open the local link in your browser.
